# Лабораторная работа: Создание XML-документа с валидной разметкой

## Задание
Создать xml файл валидной разметки с вложенностью не менее трёх уровней. Количество различных элементов второго уровня должно быть не менее двух. Количество различных элементов третьего уровня должно быть не менее четырёх. Тематика xml файла произвольная. Для каждого элемента первого уровня предусмотреть не менее 3 экземпляров, для каждого элемента последующих уровней – не менее двух экземпляров.

## Реализация
XML
Создан XML-файл index.xml с тематикой — библиотека книг.
Структура включает:

1 уровень: <library> (корневой элемент)
2 уровень: <book> — по одному элементу на каждую книгу
3 уровень: <metadata>, <content>, <analysis>
4 уровень: <facts>, <themes>, <problems>, <reviews>
Каждый <book> содержит всю необходимую структуру.

Создание CSS файла с описанием стилей элементов из index.xml
Создан файл стилей style.css, описывающий визуальное оформление элементов XML-документа:

Оформление названий книг, авторов, жанров
Цветовые акценты, стили списков (facts, themes, reviews, problems)
Общее оформление для читаемости (фон, шрифт, отступы и пр.)
