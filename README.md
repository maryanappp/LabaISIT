## Задание
- Реализовать Telegram-бота, который:
  - При запуске предлагает пользователю выбрать валюту с помощью клавиатуры.
  - Запрашивает у пользователя дату в формате `ДД/ММ/ГГГГ`.
  - Получает курс выбранной валюты на заданную дату с сайта ЦБ РФ.
  - Возвращает курс пользователю в Telegram.
- Обработать возможные ошибки (некорректный формат даты, недоступность сайта, отсутствующая валюта и т.д.).
## Дополнительно
Бот должен иметь клавиатуру с выбором из не менее чем 2 разных валют
## Реализация

- Валюты: `USD`, `EUR`  
- Источник данных: сайт Центрального банка России (`https://cbr.ru/currency_base/daily/`)  
- Используемые технологии:
  - Python
  - Библиотека `telebot` для работы с Telegram Bot API
  - `requests` для HTTP-запросов
  - `BeautifulSoup`. Библиотека для парсинга HTML-документов. В данной работе используется для: поиска таблицы с курсами на странице, извлечения строк и ячеек таблицы, получения названия валюты и её значения.

## Логика работы

1. **Старт**  
   При вводе команды `/start` пользователь получает клавиатуру с выбором валюты.

2. **Выбор валюты**  
   Пользователь выбирает `USD` или `EUR`.

3. **Ввод даты**  
   Бот предлагает ввести дату в формате `ДД/ММ/ГГГГ`.

4. **Запрос к сайту ЦБ РФ**  
   Бот формирует URL с указанной датой, выполняет `GET`-запрос и получает HTML-страницу с курсами валют.

5. **Парсинг и поиск валюты**
   - Ищется таблица на странице.
   - В таблице находится строка с нужным валютным кодом (`USD` или `EUR`).
   - Если валюта найдена — возвращается её курс.
