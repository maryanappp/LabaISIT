## Задание
Задание на эту лабораторную работу такое же, как и для предыдущей, однако реализовать её нужно с помощью async/await. Необходимо создать HTML страницу с встроенным скриптом, который будет в зависимости от варианта выполнять следующие действия:
● собирать список id аккаунтов, являющихся друзьями тех, кто состоит в определенной группе или встрече.
## Дополнительное задание
Создать поле ввода. В поле ввода вводится число, которое ограничивает общее количество аккаунтов, лайков, друзей, постов или групп, с которыми вам нужно работать
## Реализация
В работе написан вложенный в HTML документ скрипт на JavaScript, который при помощи методов VK API асинхронно собирает список ID друзей участников заданной группы. Пользователь может указать ID группы, число участников для обработки и количество друзей у каждого участника через поля ввода. Код использует async/await для упрощения работы с промисами и повышения читаемости.

## Технологический стек

- **Язык программирования:**  
  JavaScript (ES6+) — используется для написания логики сбора данных через VK API с применением современных возможностей асинхронного программирования (async/await).

- **Веб-технологии:**  
  - HTML5 — создание структуры и разметки веб-страницы с элементами формы и вывода результатов.  
  - CSS3 — стилизация веб-страницы для улучшения внешнего вида и удобства использования.

- **API:**  
  VK API (версии 5.131) — интерфейс для взаимодействия с социальной сетью «ВКонтакте», получения информации о группах, пользователях и их друзьях. Используется метод JSONP для обхода ограничений CORS.

- **Асинхронное программирование:**  
  async/await — для упрощения работы с асинхронными запросами к VK API, повышения читаемости и удобства поддержки кода.

- **Браузерная среда выполнения:**  
  Код запускается в браузере, использует возможности DOM API для динамического создания скриптов и элементов на странице.

- **Методы запросов:**  
  JSONP — для осуществления кросс-доменных AJAX-запросов к VK API.
