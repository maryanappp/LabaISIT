## Задание
Создать HTML страницу с встроенным скриптом, который будет в зависимости от варианта выполнять следующие действия:
●  собирать список id аккаунтов, являющихся друзьями тех, кто состоит в определенной группе или встрече
## Дополнительное задание
Создать поле ввода. В поле ввода вводится число, которое ограничивает общее количество аккаунтов, лайков, друзей, постов или групп, с которыми вам нужно работать.
## Реализация
Создан документ html, который, использует методы VK API, собирает список id аккаунтов, являющихся друзьями тех, кто состоит в определенной группе или встрече. Количество групп задается в специальном поле для ввода. Код реализован с использованием вложенных запросов.
