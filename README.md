## Задание
Создать HTML страницу с встроенным скриптом, который будет в зависимости от варианта выполнять следующие действия:
● Ставить лайки

## Реализация
Внутри HTML-документа реализован JS-скрипт, который через методы VK API (`likes.add` и `likes.delete`) отправляет запросы на постановку и снятие лайков с постов.

## Пример работы 
- Пользователь вводит ID владельца и ID поста ВКонтакте.
- Нажимает кнопку «👍 Лайкнуть пост» — на пост ставится лайк.
- При нажатии «👎 Убрать лайк с поста» — лайк удаляется.
- В случае ошибки выводится сообщение с описанием проблемы.

Особенности реализации 
- Использован VK API версии 5.131.
- Авторизация через ключ Implicit Flow (токен указан в скрипте).
- Валидация введённых ID — проверка на пустоту и числовой формат.
- Простая и чистая стилизация интерфейса с адаптивным центром экрана.

### Используемые технологии 
- VK API методов wall.createComment, likes.add, wall.getComments
- JSONP с кастомным callback
- Прокси-сервер CORS Anywhere
- Современный JavaScript
