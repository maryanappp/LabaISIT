# Лабораторная работа: Создание XML-документа с валидной разметкой

## Задание
Создать xml файл валидной разметки с вложенностью не менее трёх уровней. Количество различных элементов второго уровня должно быть не менее двух. Количество различных элементов третьего уровня должно быть не менее четырёх. Тематика xml файла произвольная. Для каждого элемента первого уровня предусмотреть не менее 3 экземпляров, для каждого элемента последующих уровней – не менее двух экземпляров.

## Реализация
XML

Создание XML файла с элементами и вложенностью не менее трех.

CSS

Создание CSS файла с описанием стилей элементов из index.xml

## Проверка требований 
Уровни вложенности:
1 уровень: корневой элемент <library>
2 уровень: элементы <book>
3 уровень: структурные компоненты (<metadata>, <content>, <analysis>)
4 уровень: тематические элементы (<facts>, <themes>, <problems>, <reviews>)
Количество элементов:
Элементов 1-го уровня: 3 (по одному на каждую книгу)
Элементов 2-го уровня: 3 типа (<metadata>, <content>, <analysis>)
Элементов 3-го уровня: 4 типа (<facts>, <themes>, <problems>, <reviews>)
Вложенных элементов: минимум 2 экземпляра каждого типа
Валидность:
Корректное объявление XML (<?xml version="1.0"?>)
Правильная вложенность тегов
Закрытие всех элементов
