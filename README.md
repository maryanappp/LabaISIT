## Задание
Цель лабораторной работы — создать интерактивное меню (клавиатуру) для Telegram-бота с помощью библиотеки pyTelegramBotAPI.
Меню должно содержать не менее восьми различных кнопок, иметь вложенность минимум два уровня, то есть при выборе пункта меню бот должен отправлять новую клавиатуру с дополнительными вариантами. На каждое нажатие кнопки бот должен отвечать соответствующим сообщением и вести счетчик количества нажатий по каждой клавише.
## Дополнительное задание

Напишем код бота с меню, который будет помогать выбрать завтрак, обед или ужин и их рецепты . Также реализуем счетчик нажатий клавиш.
## Реализация
- Для работы используется язык программирования **Python** и библиотека **telebot** (pyTelegramBotAPI).
- Бот запускается с помощью токена, полученного у [@BotFather](https://t.me/BotFather) в Telegram.
- В меню реализованы 4 категории рецептов: **Завтраки**, **Обеды**, **Десерты** и **Напитки**.
- При выборе категории пользователь получает клавиатуру с конкретными блюдами.
- При выборе блюда бот отправляет рецепт.
- Кнопка **"Назад"** возвращает пользователя в главное меню.
- Для каждой кнопки ведется счетчик количества нажатий, который отображается после каждого выбора.

## Технологический стек

- **Язык программирования:** Python 3.x
- **Библиотека для Telegram-бота:** pyTelegramBotAPI (`telebot`)
- **Среда выполнения:** Локальный компьютер или удалённый сервер с доступом в интернет
- **Telegram Bot API** — интерфейс для взаимодействия с Telegram
