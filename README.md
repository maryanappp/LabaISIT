## Задание
Создать HTML страницу с встроенным скриптом, который будет в зависимости от варианта выполнять следующие действия:
●  собирать список id аккаунтов, являющихся друзьями тех, кто состоит в определенной группе или встрече
## Дополнительное задание
Создать поле ввода, куда вводится число, ограничивающее общее количество аккаунтов, лайков, друзей, постов или групп, с которыми нужно работать.
## Реализация
Создан документ html, который, использует методы VK API, собирает список id аккаунтов, являющихся друзьями тех, кто состоит в определенной группе или встрече. Количество групп задается в специальном поле для ввода. Код реализован с использованием вложенных JSONP-запросов для работы с VK API и обхода ограничений CORS.

## Технологический стек
- **VK API:** методы  
  - `groups.getMembers` — получение участников группы  
  - `friends.get` — получение списка друзей пользователя  
  - `users.get` — получение информации о пользователе  

- **JSONP** — для выполнения кросс-доменных запросов с использованием кастомного callback.  

- **jQuery** — для удобного выполнения AJAX JSONP запросов.  

- **Прокси-сервер CORS Anywhere** (при необходимости) — для обхода политики CORS в браузерах.  

- **Современный JavaScript (ES6+)** — реализация логики вложенных запросов и обработки данных.  

- **HTML5 и CSS3** — разметка и стилизация интерфейса страницы.
