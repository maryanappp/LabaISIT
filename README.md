## Задание
Создать бота для Telegram. Послать ему сообщение со своего аккаунта. С помощью API прочитать это сообщение. Создать HTML файл, который с помощью JavaScript по API прочитает это сообщение и выведет его на странице.
## Реализация
Прежде чем начинать разработку, зарегистрируем бота, получив его уникальный id, являющийся одновременно и токеном. Для этого в Telegram существует специальный бот —@BotFather.
Далее напишем скрипт JS, который будет, используя методы Telegram API читать отправленное ему сообщение определенного пользователя и выводить это сообщение вместе с ником пользователя на странице.
