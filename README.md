## Задание
Принять текстовое сообщение от собеседника бота. Отправить его в социальную сеть вконтакте.
Вариант:
1. Сделать пост у себя на странице с текстом

## Реализация
Напишем код бота с меню на питоне, который будет иметь возможность оставлять комментарий на странице с текстом, введенным пользователем.
