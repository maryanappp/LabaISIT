## Задание
Принять текстовое сообщение от собеседника бота. Отправить его в социальную сеть вконтакте.
Вариант:
1. Сделать пост у себя на странице с текстом

## Реализация
Данная лабараторная работа реализует взаимодействие между Telegram и VK с помощью бота, который получает сообщения из Telegram и публикует их в виде комментариев к последнему посту на странице ВКонтакте.

## Основной алгоритм работы

1. Пользователь отправляет сообщение в Telegram-бот.
2. Бот принимает сообщение.
3. Формирует текст комментария.
4. Получает ID последнего поста на стене VK.
5. Публикует комментарий под этим постом.
6. Отправляет ответ пользователю в Telegram (успешно/ошибка).

## Технологический стек

- Язык программирования: Python 3
- Библиотеки:
  - `pyTelegramBotAPI` (`telebot`) — для взаимодействия с Telegram API
  - `requests` — для HTTP-запросов к API ВКонтакте
- API:
  - Telegram Bot API
  - VK API (версии 5.131)
