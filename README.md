## Задание
Создать HTML страницу с встроенным скриптом, который будет в зависимости от варианта выполнять следующие действия:
● Ставить лайки
## Реализация
Напишем вложенный скрипт JS внутри документа html, который будет, используя методы VK API, ставить лайки в социальной сети ВК.
