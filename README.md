## Задание
Создать HTML страницу с встроенным скриптом, который будет обрабатывать выданный вам XML файл. Вам необходимо вывести на экран все элементы третьего, последнего уровня вложенности одного из элементов второго уровня.

## Дополнительное задание:

В HTML файле создать поле ввода, в которое вводиться номер элемента второго уровня, для которого выведутся элементы третьего уровня

## Реализация
На основе XML-файла из предыдущей лабораторной работы была создана HTML-страница index.html с подключённым JavaScript-файлом script.js, который:

- Загружает XML-файл book.xml
- Обрабатывает выбранный элемент <book> по номеру
- Выводит на экран значения его вложенного элемента <details>
- Реализована валидация: проверка ввода и допустимости номера книги
Создан файл стилей styles_parser.css с оформлением всех визуальных элементов: поля ввода, кнопки, списков и структуры отображения информаци

Пример структуры XML
'''<book>
   <details>
       <title>Маленький принц</title>
       <author>Антуан де Сент-Экзюпери</author>
       <year>1943</year>
       <genre>Сказка</genre>
       <pages>96</pages>
   </details>
</book>'''

## Пример работы 
Ввод: Пользователь вводит номер книги.

Вывод: На экран выводится информация о выбранной книге: название, автор, год, жанр и количество страниц.
