## Задание
Создать бота для Telegram. Отправить ему сообщение со своего аккаунта. С помощью Telegram API прочитать это сообщение. Создать HTML файл, который с помощью JavaScript по API прочитает это сообщение и выведет его на странице.
## Реализация
1. **Регистрация бота**  
   Для начала зарегистрируем бота в Telegram через @BotFather, получив уникальный токен, необходимый для взаимодействия с Telegram API.

2. **Написание скрипта**  
   Создан HTML файл с JavaScript, который использует методы Telegram API для получения обновлений (сообщений) от бота. Скрипт фильтрует сообщения и выводит текст сообщений вместе с именем отправителя.

3. **Основные возможности интерфейса:**  
   - Кнопки для отображения всех сообщений, первого сообщения.  
   - Вывод текста сообщений на странице.  
   - При отображении первого или последнего сообщения дополнительно загружается и показывается фото профиля пользователя (если оно есть).

## Используемые технологии

Telegram Bot API — для получения сообщений и данных пользователей.
JavaScript (ES6) — для асинхронных запросов к API и динамического обновления страницы.
HTML5 и CSS3 — для создания пользовательского интерфейса.

## Инструкция по запуску

 - Зарегистрируйте Telegram бота через @BotFather и получите токен.
 - Вставьте токен в переменную token в HTML-файле.
 - Откройте HTML-файл в браузере.
 - Отправьте сообщение боту из вашего аккаунта Telegram.
 - Используйте кнопки на странице для просмотра сообщений.
