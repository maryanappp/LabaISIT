## Задание
Создать инлайн-клавиатуру для вашего бота. Результаты выбора должны фиксироваться.
## Реализация
Разработан Telegram-бот на Python с использованием библиотеки **pyTelegramBotAPI** (`telebot`), который предлагает пользователю меню с выбором категорий рецептов и подменю с конкретными блюдами. При выборе блюда бот отправляет описание рецепта.

- Используется инлайн-клавиатура для выбора категории и блюд.
- Обработка нажатий реализована через callback-запросы.
- Меню содержит категории: Итальянская, Японская, Мексиканская кухня и Десерты.
- После выбора блюда отображается рецепт.
- Поддерживается кнопка возврата в главное меню.
