## Задание
Создать инлайн-клавиатуру для вашего бота. Результаты выбора должны фиксироваться.
## Реализация
Напишем код бота с инлайн-меню на питоне, который будет предлагать выбор на каждое свое сообщение. Этот бот поможет выбрать и посмотреть рецепты популярных блюд.
